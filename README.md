# Chaerul Umam — Portfolio v3

A clean, soft, professional developer portfolio based on the information in the supplied CV.

## Design changes
- White base with soft blue/lavender/mint accents.
- Portfolio screenshots are cleaned so the CV's heading/caption text is not displayed inside the project images.
- Certificate photos/PDF previews are not displayed.
- Assistant Laboratory remains in the professional experience timeline, not as a certificate image.
- Mouse-follow glow, cursor interaction, scroll reveal, hover lift, and 3D tilt interactions.
- Project cards open a detail modal.
- Responsive and mobile friendly.

## Publish
Upload the folder to GitHub and deploy the static site to GitHub Pages, Netlify, or Vercel.

## Replace before publishing
- LinkedIn URL if you want one displayed.
- Any project URLs if you have public demos.
- Keep the CV PDF in `assets/CV-Chaerul-Umam.pdf` for the download button.
